# Nishtek PDF

Free PDF editor that runs in your browser, by [Nishtek](https://www.instagram.com/nishkambhatia/).

Edit text, sign, highlight, draw, fill forms, merge, split, reorder, rotate, compress, and convert PDFs and images.
Everything happens on your device. Files are never uploaded.

Built with pdf.js and pdf-lib. Fonts: DejaVu Sans, Dancing Script and Caveat (open licences).
